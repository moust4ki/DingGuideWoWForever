# DingDB corrections and additions

Each `NN_topic.lua` file of this folder corrects or adds game data on top of Questie's
(quests, NPCs, objects, items, names in other languages). `tools/build_data.lua` applies them
in name order when it builds `Ding/DB`; `tools/check_data.lua` checks them.

The format, with examples, is in [docs/dingdb.md](../../../docs/dingdb.md#3-contributing-corrections-and-additions).
